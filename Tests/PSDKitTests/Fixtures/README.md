# Test fixtures

These PSD/PSB files are psd-tools' own test files
(https://github.com/psd-tools/psd-tools/tree/main/tests/psd_files), used and
redistributed under its MIT licence — see `LICENSE-psd-tools`.
`layers-minimal_type-layer.psd` is `layers-minimal/type-layer.psd` there.

`agpsd-text-layer.psd` is ag-psd's `test/read/text-layer/src.psd`
(https://github.com/Agamnentzar/ag-psd), used and redistributed under its MIT
licence — see `LICENSE-ag-psd`. It is set in Myriad Pro, which a Mac without
Adobe's apps does not have: the real missing-font case.
